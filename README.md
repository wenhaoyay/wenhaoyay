## Featured project

### [Along](https://github.com/wenhaoyay/along-sg)

A journey-aware errand planner for Singapore public transport. Instead of finding only the nearest place, Along compares possible stops against the user's existing journey and ranks them by added travel time, walking and transfers.

**Built with:** Python · FastAPI · TypeScript · Next.js · React · SQLite/FTS5 · OneMap
