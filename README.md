### Along-SG
A full-stack routing and optimisation project built around a simple product question: **where should I complete an errand if I am already travelling from A to B?**

The backend combines location resolution, POI discovery, candidate pruning, public-transport routing and preference-aware scoring. The frontend presents the resulting route trade-offs in a map-first planner.

**Engineering focus:** routing optimisation · geospatial search · API integration · full-stack architecture · deterministic fallbacks

### Critter Heist
A multiplayer collection/heist game where consequential gameplay state is controlled by the server.

The public snapshot focuses on persistent player profiles, session leases, crash-tolerant player-to-player ownership transfers, server-side interaction validation, progression/economy rules and eight-player QA scenarios.

**Engineering focus:** distributed state · persistence · concurrency · server authority · reliability

### Find the Defect!
A factory quality-control game where products move through an inspection line and players identify defective units.

The public snapshot focuses on schema-safe persistence, authoritative inspection logic, product/defect generation, physical line progression, factory projects and rare anomaly discovery.

**Engineering focus:** data-driven systems · state machines · persistence · progression design · simulation logic
