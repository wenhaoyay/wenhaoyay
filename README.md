## Featured projects

### [Assay](https://github.com/wenhaoyay/assay) — AI evaluation & regression testing

Evaluate RAG chatbots and tool-using agents with versioned golden datasets, deterministic checks, calibrated judges and execution traces. Compare versions case by case with confidence intervals, then apply explicit regression gates in the app or CI.

**Focus:** evaluation design · retrieval metrics · judge calibration · statistical comparison · release gates  
**Stack:** Python · FastAPI · React · TypeScript · SQLite / PostgreSQL

### [ExperimentLab](https://wenhao-site.pages.dev/side/experimentlab.html) — A/B testing & decision analytics

Plan experiments and validate their data before interpreting effects. Sample-ratio mismatch blocks inference; confidence intervals, CUPED, practical significance and guardrails make uncertainty and business trade-offs explicit.

**Focus:** experiment design · data integrity · statistical inference · decision support  
**Stack:** Python · FastAPI · SciPy · statsmodels · DuckDB · React · TypeScript  
*Portfolio case study; source repository is currently private.*

### [Along-SG](https://github.com/wenhaoyay/along-sg) — Journey-aware optimisation

A Singapore public transport planner that fits errands into an existing journey. It ranks candidate stops by added travel time, walking and transfers, using geospatial search and deterministic routing optimisation.

**Focus:** routing algorithms · geospatial search · API integration · full-stack development  
**Stack:** Python · FastAPI · Next.js · React · TypeScript · SQLite / FTS5

### [Critter Heist](https://github.com/wenhaoyay/critter-heist) — Multiplayer backend systems

Server-authoritative Roblox systems with persistent player profiles, session leases and crash-tolerant ownership transfers. The public engineering snapshot includes concurrency handling, exploit-resistant validation and multiplayer QA evidence.

**Focus:** persistence · distributed state · concurrency · reliability  
**Stack:** Luau · Roblox DataStore

**Other projects:** [Find the Defect!](https://github.com/wenhaoyay/find-the-defect) — factory inspection simulation with data-driven defect generation, authoritative state transitions and defensive persistence.
